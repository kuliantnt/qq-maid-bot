# 设计

概念：从一句对话，到日常事务的助手。温暖的女仆 Logo 与清晰的开发者 UI 配合。

画布 1920×1080。背景 #fbf7f8，正文 #30292f，次级文字 #71616c，强调 #af315e，面板 #fffdfd，浅粉 #f5dce5，边框 #e5d4dc。
中文使用本地嵌入 Noto Sans CJK SC，400/700；技术标签使用本地 DejaVu Sans Mono。中文选择以完整字形和可读性为先。标题 76–110px，正文 32–40px，标签 24–28px。圆角 24–40px，间距 24–80px，轻阴影。
每段有明确主标题、内容区和边缘序号。Logo 原图不重绘；无渐变文字，无虚构指标。入场使用 staggered-fade-up 与 spring-pop-entrance，有限 sine-wave-loop 只用于背景。固定时间切换，内容内层完成出入场。
